# Python Quiz Application

## About
This is a simple Python-based Quiz Application. It asks multiple-choice questions and calculates the user's score.

## Features
- Multiple-choice questions
- Answer validation
- Automatic score calculation
- Percentage calculation
- Performance message
- Replay option
- Instructions menu

## Technologies Used
- Python

## How to Run
1. Open the project folder.
2. Run `quiz.py` using Python.
3. Select an option from the menu.
4. Answer the quiz questions and view your result.
